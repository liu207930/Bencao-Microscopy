# Bencao-Microscopy
《本草显微》是一款把中药“性味归经”与“显微特征”收进同一张纸的离线速查工具。 药典里的“簇晶”“石细胞”精确却抽象，显微照片又难标注、难打印，于是我们把显微镜下的纹理翻译成一张可读、可收藏、可打印的本草卡片：一药一卡，从药名、拉丁名、性味归经，到功效与手绘显微图，形成“宏观药性—微观物性”的对照。 视觉取纸色、墨色与朱砂，借图版编号、引线、印章，让屏幕像一页摊开的本草谱； 图形用 SVG 参数化绘制，只提炼识别特征，保留手绘的轻微抖动。 单文件、零依赖、离线可用，支持拼音检索、收藏夹与打印。 它是学习示意，不是鉴定依据——不替代药典，也不替代显微镜，只把两者之间最难跨的想象，铺成一张纸。
